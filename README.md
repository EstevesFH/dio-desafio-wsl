# 🔍 Buscador de Repositórios GitHub – Desafio DIO

## 📖 Descrição

Este projeto foi desenvolvido como parte de um **desafio da plataforma DIO (Digital Innovation One)**.  
O objetivo inicial do desafio era criar um **sistema de busca de repositórios do GitHub**, consumindo a **API pública do GitHub**.

A partir da base proposta no desafio, implementei **funcionalidades extras** para melhorar a experiência do usuário e a usabilidade da aplicação.

---

## 🚀 Funcionalidades

- 🔎 Busca de repositórios do GitHub utilizando a **API do GitHub**
- ⚠️ Exibição de **mensagem de alerta** quando o campo de busca está vazio
- ❌ Funcionalidade para **remover repositórios** já buscados da lista
- 📋 Listagem dinâmica dos repositórios encontrados
- 💻 Interface simples e intuitiva

---

## 🛠️ Tecnologias utilizadas

- **React**

## ▶️ Como executar o projeto

1. Clone o repositório:
```bash
git clone https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git
````

2. Acesse a pasta do projeto:

```bash
cd nome-do-projeto
```

3. Instale as dependências:

```bash
npm install
```

ou, se usar Yarn:

```bash
yarn
```

4. Inicie o projeto:

```bash
npm start
```

ou:

```bash
yarn start
```

5. Acesse no navegador:

```
http://localhost:3000
```
